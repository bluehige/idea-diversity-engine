# Patent Idea Workbench

**Status: Planned**  
**Vertical: `ip-invention`**

기술 문제 인터뷰부터 발명 후보, 설계회피, 선행기술 검색어, 실험 증거, 청구항 씨앗까지 연결하는 워크벤치입니다.

## 주요 화면

1. 기술 문제·기존 구조 입력
2. 구조·센서·제어·데이터·운영·안전 해결 공간 지도
3. 발명 후보 카드와 의미 중복 클러스터
4. 구성·연결·작동·효과 비교표
5. 검색 키워드·분류·경쟁 구조 기록
6. 최소 실시예·변형 실시예
7. 검증 실험과 증거 확보 계획
8. 발명 제안서 Markdown/JSON 내보내기

전형성 값은 신규성·진보성·등록 가능성으로 표시하지 않으며, 선행기술 및 법률 검토를 별도 단계로 둡니다.
