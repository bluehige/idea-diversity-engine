# Narrative Lens Panel

**Status: Prototype**  
**Vertical: `creative-writing`**

하나의 소설 발제를 20개의 **추상화된 서사 설계 관점**으로 검토합니다. 실존 작가의 문체나 고유 스타일을 복제하는 앱이 아닙니다.

## 렌즈 예시

- 증거물형 오컬트
- 하드보일드 생존
- 품격형 흥행
- 제약 기반 두뇌전
- 약속·카타르시스
- 회색 군상극
- 오해·소동
- 여백형 청춘 심리
- 대모험·동료
- 생활·생태 세계관

## 출력

각 렌즈는 다음 네 부분을 요구합니다.

1. 가장 약한 지점 진단
2. 해당 관점에서 가능한 개선 장치 2~3개
3. 끝까지 지켜야 할 핵심 원칙
4. 다음 설계를 결정하는 질문 1개

추가로 VS 후보 5개를 생성하되 전형성과 품질을 분리하고, 비공개 사고과정 대신 짧은 근거만 출력합니다.

`index.html`은 API 키 없이 사용하는 공급자 중립 프롬프트 작성기입니다.
