# Character Starter

**Status: Prototype**  
**Verticals: `creative-writing`, `ai-character`**

캐릭터 설정표를 많이 채우는 대신, 첫 장면에서 바로 작동하는 **욕망·약점·관계·행동 엔진**을 설계합니다.

## 핵심 입력 9개

1. 임시 호칭
2. 역할 원형
3. 눈에 띄는 외형·소품·행동
4. 겉과 속의 모순
5. 지금 가장 원하는 것
6. 사건을 꼬이게 만드는 약점
7. 방해자 또는 나쁜 사건
8. 타인이 떠드는 소문
9. 대사 없이도 보이는 행동 시그널

## 출력

- 한 줄 소개
- 첫 등장 장면
- 주인공·라이벌·트리커 관계 삼각형
- 제3자 소문 3개
- 행동 규칙 5개
- 위기·호감·약점 노출 장면 테스트
- 식별성·모순성·추진력·취약성·사회성·연출성 평가

## 검증 규칙

- 욕망은 명사가 아니라 행동 목표여야 합니다.
- 약점은 과거 설명이 아니라 현재 사건을 만들어야 합니다.
- 형용사만 있고 보이는 특징이 없는 캐릭터는 재작성합니다.
- 방해자·소문·관계가 없는 고립된 프로필을 허용하지 않습니다.

`index.html`은 입력 내용을 DGE 캐릭터 생성 프롬프트로 변환하는 로컬 프로토타입입니다.
