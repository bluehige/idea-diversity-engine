# Safety Scenario Studio

**Status: Planned**  
**Vertical: `safety-training`**

산업안전 교육 시나리오를 단순 줄거리로 만들지 않고, 센서·입력·분기·판정·UI·나레이션·교육효과까지 하나의 제작 명세로 구성합니다.

## 주요 화면

- 작업·교육대상·현장환경 입력
- 장비·센서·HMD 매핑
- 사고 전조와 사용자 행동 분기
- 성공·실패·부분성공 판정
- UI·음성 피드백
- 난이도·현지화 변형
- PC·VR·키오스크 출력 조건
- 온라인·오프라인 연계 패키지

## 검수

안전 전문가, 현장 담당자, 하드웨어 개발자가 각각 교육 정확성, 판정 재현성, 장비 구현성을 승인해야 합니다.
