# Game Content Forge

**Status: Planned**  
**Vertical: `game-design`**

기존 게임 시스템을 재사용하면서도 플레이어에게 다른 선택을 만드는 몬스터, 스킬, 건물, 함정, 보스, 시즌, 다회차 엔딩을 설계합니다.

## 주요 화면

- 핵심 루프와 현재 피로 지점
- 전투·경제·성장 제약
- 몬스터 역할·스킬·상성 포트폴리오
- 건물·함정·배치 조합
- 보스 페이즈와 텔레그래프
- 시즌 이벤트와 보상 루프
- 엔딩 조건과 회차 간 변화
- 밸런스 가설과 플레이테스트 질문

생성 결과는 재미를 보장하지 않으므로 수치 시뮬레이션과 실제 플레이테스트를 별도 단계로 둡니다.
