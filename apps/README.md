# Applications

앱은 Core와 Vertical을 실제 업무 흐름으로 묶는 사용자 인터페이스입니다.

## 앱 원칙

- 앱마다 사용하는 Vertical과 출력 문서를 명시합니다.
- 공통 VS 규칙을 앱마다 별도로 복제하지 않습니다.
- API 키는 공개 배포에서 브라우저 `localStorage`에 저장하지 않습니다.
- 전형성은 품질·성공률처럼 표시하지 않습니다.
- 실존 작가·브랜드의 스타일 직접 모방보다 추상화된 설계 관점을 사용합니다.
