# Diversity Playground

**Status: Planned**

동일한 브리프와 동일한 총 후보 예산으로 다음 방식을 비교하는 공개 데모입니다.

- Direct: 한 번에 한 후보
- List: 확률 없는 후보 목록
- VS: 후보와 전형성 추정치
- Stratified VS: 해결 공간을 층화한 뒤 VS 생성

## 화면

- 입력 브리프와 Vertical 선택
- 후보 카드와 Head/Mid/Tail 표시
- 의미 중복 클러스터
- 제약 통과율
- 품질·구현성 점수
- 비용·지연 비교
- JSON/Markdown/CSV 내보내기

전형성은 품질 점수와 시각적으로 분리합니다.
