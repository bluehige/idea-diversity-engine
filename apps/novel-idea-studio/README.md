# Novel Idea Studio

**Status: Prototype**  
**Vertical: `creative-writing`**

소설·웹소설 발제를 제목, 세계관, 캐릭터, 플롯, 엔딩의 **서로 다른 후보 포트폴리오**로 확장하기 위한 앱입니다.

## v0.2 프로토타입

`index.html`은 API 키 없이 실행되는 **공급자 중립 프롬프트 작성기**입니다.

1. 장르와 발제를 입력합니다.
2. 생성 범위와 다양성 모드를 선택합니다.
3. DGE 규칙이 포함된 프롬프트를 생성합니다.
4. ChatGPT, Claude, Gemini, 로컬 LLM 등에 붙여 넣습니다.

## 출력 모듈

- 제목: 구조, 핵심 훅, 전형성, 클리셰 위험
- 세계관: 핵심 규칙, 일상적 결과, 갈등, 구현 위험
- 캐릭터: 호칭, 역할원형, 겉속모순, 욕망, 약점, 행동 시그널
- 플롯: 1막 훅, 중반 전환, 최종 선택, 복선 회수
- 엔딩: 조건, 대가, 주제 결론, 다음 회차 유도
