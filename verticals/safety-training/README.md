# 안전교육·시뮬레이션
### Safety Training Vertical

사고 이야기를 반복 생성하는 것이 아니라 **작업환경·인적요인·장비·센서·판정·피드백·복구**를 결합한 제작 가능한 안전교육 시나리오를 만듭니다.

## 입력

- 작업 종류와 교육 대상
- 현장 환경과 위험요인
- 장비·HMD·센서·입력장치
- 반드시 학습할 행동
- 성공·실패 평가 방식
- 금지 연출과 현지화 조건

## 출력

- 사고 전조와 근접사고 후보
- 사용자 행동 분기
- 장비·센서 입력 매핑
- 성공·실패·부분성공 판정
- UI 경고와 나레이션
- 난이도 변형
- PC·VR 구현 조건
- 온라인·오프라인 연계 명세

## 품질·위험 게이트

- 예방과 교육 목적이 명확한가
- 충격적 장면만 있고 학습 행동이 없는가
- 센서가 실제 하드웨어에서 구현 가능한가
- 판정 기준이 재현 가능한가
- 안전 전문가와 현장 담당자의 검수를 거쳤는가
