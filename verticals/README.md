# Vertical Extension Packs

수직 확장팩은 Core 엔진에 **분야별 입력 구조, 탐색축, 프롬프트, 평가 기준, 예제, 제작 문서 변환 규칙**을 추가합니다.

## 표준 구조

```text
verticals/<vertical-id>/
├─ README.md          # 목적, 입력, 출력, 검토 범위
├─ manifest.yaml      # 향후 기계 판독용 메타데이터
├─ prompts/           # 분야별 생성 규칙
├─ schemas/           # 분야별 입출력 구조
├─ rubrics/           # 품질·위험 평가 기준
├─ skills/            # 에이전트 작업 절차
├─ exporters/         # 실제 제작 문서 변환 규칙
└─ examples/          # 브리프와 결과 사례
```

v0.2에서는 각 확장팩의 README와 기존 프롬프트·예제 연결을 먼저 구성합니다. 신규 프롬프트와 스키마는 `verticals/_template/` 기준으로 추가합니다.

## 원칙

- Core 로직을 수직팩마다 복제하지 않습니다.
- 전형성과 품질·사실성·실현가능성을 분리합니다.
- 분야별 필수 사람 검토 범위를 명시합니다.
- 새 확장팩은 최소한 입력, 출력, 탐색축, 품질기준, 위험, 예제를 포함합니다.
