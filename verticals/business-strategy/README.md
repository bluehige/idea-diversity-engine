# 사업·서비스 전략
### Business Strategy Vertical

고객·가치·수익·채널·운영·파트너·위험을 분리하여, 서로 다른 **사업모델과 시장진입 경로의 포트폴리오**를 생성합니다.

## 입력

- 대상 고객과 해결할 문제
- 현재 대안과 경쟁 방식
- 보유 기술·데이터·인력·유통 자산
- 가격·규제·기간·지역 제약
- 검증 가능한 증거와 아직 모르는 가정

## 출력

- 가치제안 후보
- 수익모델과 비용구조
- 판매·배포 채널
- 파트너십과 운영모델
- 시장진입 순서
- 가장 위험한 가정
- 저비용 검증 실험
- 중단·전환 기준

## 품질 게이트

시장 규모나 전환율을 임의로 발명하지 않습니다. 독창성보다 고객 문제 강도, 지불의사, 실행비용, 규제, 반복매출, 검증 가능성을 별도 평가합니다.
