# 3D·비주얼 디자인
### Visual and 3D Design Vertical

이미지 스타일만 바꾸는 대신 **실루엣·질량·구조·부품·재질·리깅·LOD·엔진 제약**이 다른 제작 가능한 콘셉트를 생성합니다.

## 입력

- 사용 목적과 플랫폼
- Unity·Unreal·Godot 등 대상 엔진
- 폴리곤·재질·텍스처 예산
- 리깅·모듈화·애니메이션 조건
- 제작 기간과 인력
- 스타일과 금지 요소

## 출력

- 실루엣 후보
- 구조와 부품 분할
- 정면·측면·후면 요구사항
- 재질 언어와 파손 표현
- 본·리깅·콜라이더 계획
- LOD·UV·텍스처 최적화
- 이미지·영상 생성 프롬프트
- 모델링 작업분해표

## 품질 게이트

브랜드·저작권 모방 위험, 실제 조립·리깅 가능성, 게임 화면 가독성, 드로우콜·메모리 예산, 제작기간을 별도 검토합니다.
