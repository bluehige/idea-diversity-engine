# 소설·서사 생성
### Creative Writing Vertical

소설·웹소설·웹툰·영상 서사의 제목, 세계관, 캐릭터, 플롯, 장면, 대사, 엔딩을 **표현만 다른 목록이 아니라 서로 다른 서사 메커니즘의 포트폴리오**로 생성합니다.

## 입력

- 장르와 핵심 발제
- 목표 독자와 플랫폼
- 원하는 정서·톤
- 반드시 지킬 설정
- 피해야 할 클리셰와 금지 요소
- 연재 길이와 제작 제약

## 탐색 층

1. 제목 구조와 핵심 훅
2. 세계 규칙과 일상적 결과
3. 캐릭터 욕망·약점·관계 엔진
4. 정보 공개와 사건 구조
5. 승리조건·대가·반전
6. 주제 결론과 엔딩 조건

## 출력

- 제목 포트폴리오
- 세계관 포트폴리오
- 행동 중심 캐릭터 카드
- 관계 삼각형과 첫 등장 장면
- 플롯 분기와 복선 회수표
- 다회차 또는 복수 엔딩 조건
- 이미지·영상 콘셉트 프롬프트
- 제작용 소설 기획 문서

## 품질 게이트

- 장르 훅이 1~2문장 안에 보이는가
- 후보가 배경 이름만 다르고 구조는 같은 상태가 아닌가
- 캐릭터가 프로필이 아니라 욕망과 행동으로 움직이는가
- 세계 규칙이 사건과 일상에 실제 영향을 주는가
- 엔딩이 감정 라벨이 아니라 조건과 대가로 구분되는가
- 특정 실존 작가의 문체를 직접 모방하지 않는가
