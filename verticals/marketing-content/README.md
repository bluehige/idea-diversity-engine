# 마케팅·콘텐츠
### Marketing Content Vertical

동일한 혜택 문구, 공포 자극, 할인, 기능 나열로 수렴하지 않도록 **타깃·증거·메시지·채널·형식·전환 단계**를 나누어 캠페인 포트폴리오를 생성합니다.

## 입력

- 타깃과 구매 단계
- 제품·서비스의 실제 증거
- 채널과 콘텐츠 형식
- 브랜드 톤과 금지 표현
- 지역·언어·문화 현지화 조건

## 출력

- 캠페인 방향
- 메시지·카피 앵글
- 콘텐츠 포맷과 연재 구조
- 고객 여정별 CTA
- 증거 제시 방식
- KPI 가설과 A/B 테스트
- 제작 난도와 브랜드 위험

## 품질 게이트

허위 수치, 근거 없는 최상급 표현, 사고 피해자에 대한 자극적 묘사, 문화적 오해를 배제합니다. 참신함과 전환 가능성은 별도 축으로 평가합니다.
