# 연구·합성데이터
### Research and Synthetic Data Vertical

가설과 데이터의 개수만 늘리는 대신 **원인 설명·반증 조건·측정 방법·실패 모드·재현 경로**가 다른 연구 포트폴리오를 생성합니다.

## 입력

- 연구 질문과 기존 설명
- 독립·종속·통제 변수
- 사용 가능한 데이터·장비·평가자
- 개인정보·윤리·비용 제약
- 외부 타당성과 재현성 요구

## 출력

- 상이한 가설과 경쟁 가설
- 반증 가능한 예측
- 실험·관찰 설계
- 측정 지표와 교란요인
- 실패·무효 결과의 해석
- 합성 데이터 층과 커버리지 지도
- 반복·재현 계획

## 품질 게이트

LLM 심사만으로 결론을 내리지 않습니다. 사실 근거, 반증 가능성, 외부 타당성, 표본 편향, 개인정보, 전문가 검토를 별도 평가합니다.
