# 소프트웨어 QA·엣지 케이스
### Software QA Vertical

정상 경로와 몇 개의 입력 오류만 반복하는 테스트에서 벗어나 **경계값·상태전이·권한·동시성·환경·복구**를 체계적으로 탐색합니다.

## 입력

- 기능 명세와 API 스키마
- 상태 모델과 역할·권한표
- 지원 환경과 네트워크 조건
- 데이터 보존·복구 규칙
- 운영환경에서 금지할 파괴적 행동

## 출력

- 재현 가능한 테스트 케이스
- 사전조건·입력·절차·기대결과
- 상태전이와 권한 충돌
- 동시성·재시도·중복 요청
- 네트워크·장치·브라우저 환경
- 오류 복구·롤백·데이터 일관성
- 커버리지 지도와 중복 클러스터

## 품질 게이트

무작위 입력 목록이 아니라 예상 결과와 검증 방법을 포함해야 합니다. 운영 데이터 손상, 실제 사용자 계정 오용, 비인가 보안 테스트는 금지합니다.
