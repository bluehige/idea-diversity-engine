# 게임 기획·콘텐츠
### Game Design Vertical

기존 시스템을 재사용하면서도 플레이어에게 **새로운 선택과 전략적 긴장**을 만드는 게임 콘텐츠 포트폴리오를 생성합니다.

## 입력

- 장르, 핵심 루프, 전투·경제·성장 시스템
- 현재 콘텐츠와 반복 피로 지점
- 제작 인력·기간·플랫폼 제약
- 업데이트 목표와 금지 수익모델

## 탐색 층

- 핵심 루프와 승리조건
- 몬스터 역할·스킬·상성
- 건물·함정·배치 효과
- 보스 페이즈와 정보 전달
- 보상·경제·성장
- 시즌·라이브옵스·다회차 엔딩

## 출력

- 업데이트 콘셉트 포트폴리오
- 몬스터·보스·스킬 카드
- 건물·함정 조합
- 이벤트 루프와 보상 구조
- 다회차 조건과 엔딩 분기
- 밸런스 가설과 플레이테스트 질문

## 품질 게이트

생성 단계와 수치 밸런스를 분리합니다. 저전형성 메커니즘도 제작비, 가독성, 악용 가능성, 기존 시스템 충돌, 플레이테스트 결과를 통과해야 합니다.
