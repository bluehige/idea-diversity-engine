# Vertical Pack Template

새 확장팩은 이 폴더 구조를 복사해 시작합니다.

## 필수 항목

- `id`, 한국어명, 영어명, 버전, 상태
- 대상 사용자와 해결할 문제
- 입력 필드와 출력 문서
- 4~8개의 탐색 층
- 품질·구현성·위험 루브릭
- 사람 검토가 필요한 범위
- 최소 1개의 브리프 예제

## README 작성 형식

```markdown
# 확장팩명

## 목적
## 적합한 문제 / 부적합한 문제
## 입력
## 해결 공간 층
## 출력
## 품질·위험 게이트
## 사람 검토
## 기존 프롬프트와 예제
## 로드맵
```
