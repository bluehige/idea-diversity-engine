# Contributing

Contributions are welcome for:

- new vertical prompt packs,
- evaluation datasets,
- output schemas,
- provider adapters,
- semantic deduplication methods,
- accessibility and localization,
- safety and governance improvements.

A contribution must:

1. preserve the interpretation of `typicality_estimate`,
2. separate diversity from quality and factuality,
3. avoid exposed private chain-of-thought,
4. include tests or validation examples for schema changes,
5. document third-party licenses and sources.

Use conventional commits where practical.
