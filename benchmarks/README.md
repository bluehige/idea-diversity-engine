# Benchmarks

다양성 생성 엔진의 성능은 후보 개수가 아니라 **의미 커버리지와 실제 채택 가치**로 평가합니다.

## 비교군

- Direct prompting
- List prompting
- Verbalized Sampling
- Stratified Verbalized Sampling
- Multi-batch + semantic memory

## 공통 지표

| 축 | 지표 예시 |
|---|---|
| 의미 다양성 | 1 - 평균 임베딩 코사인 유사도 |
| 구조 다양성 | 탐색 층 커버리지, 메커니즘 커버리지 |
| 중복 | 의미 중복 클러스터율 |
| 제약 | 필수·금지 조건 통과율 |
| 품질 | 도메인 루브릭, 구현성, 사실성 |
| 사용자 가치 | 최종 채택 후보 수, 수정량, 첫 유효 후보 시간 |
| 운영 | 호출 수, 토큰, 비용, 지연, 재시도율 |

## 원칙

- 전형성 값을 품질 평가에 합산하지 않습니다.
- 동일한 총 후보 수 또는 총 비용 예산으로 비교합니다.
- 자동 평가만 사용하지 않고 분야 전문가와 사용자 선택을 포함합니다.
- 각 Vertical은 별도의 품질 루브릭을 가집니다.
