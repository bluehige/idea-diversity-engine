# Public Release Checklist

## Required

- [ ] No API keys, secrets, customer data, or private prior art
- [ ] Paper and official implementation cited
- [ ] Paper PDF not redistributed
- [ ] Third-party licenses documented
- [ ] `typicality_estimate` warning visible
- [ ] Patent and high-impact disclaimers visible
- [ ] Examples pass schema validation
- [ ] Tests pass
- [ ] Korean and English README present
- [ ] Security reporting instructions present

## Recommended repository settings

- Repository: `bluehige/idea-diversity-engine`
- Visibility: Public
- Default branch: `main`
- Description: `Open toolkit for diverse LLM ideation using Verbalized Sampling, stratification, semantic memory, and quality gates.`
- Topics: `verbalized-sampling`, `llm`, `ideation`, `prompt-engineering`, `synthetic-data`, `innovation`, `patent`, `game-design`, `safety-training`, `mcp`
- Issues: Enabled
- Discussions: Enabled after the first public release
- Wiki: Disabled; keep canonical docs in the repository
- Branch protection: Require pull request and passing tests after collaborators join
