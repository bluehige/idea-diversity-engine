# Release Notes — v0.1.0

## Included

- Three reusable skill specifications
- Standard, balanced, tail, stratified, and vertical prompt templates
- Brief, candidate, and portfolio JSON Schemas
- Nine vertical example briefs
- Minimal provider-neutral Python prompt builder and structural validator
- Unit tests and GitHub Actions workflow
- Korean application, platform, business, governance, roadmap, vertical-product, and validation reports
- Apache-2.0 license, citation metadata, security policy, contribution guide, and publication scripts

## Intentionally not included

- Paper PDF
- Third-party model code
- Provider API keys or model adapters
- Web application
- Embedding-based semantic memory
- Automated semantic-diversity evaluation

The omitted implementation items remain on the roadmap. The v0.1 package is a public foundation and specification, not a finished SaaS product.
