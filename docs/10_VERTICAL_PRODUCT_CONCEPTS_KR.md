# 10. 우선 개발할 수직 제품

## 평가 기준

- 보유 도메인과의 적합성
- 고객 문제의 강도
- 차별화 가능성
- 제작 난도
- 반복 매출 가능성
- 법적·운영 위험

아래 점수는 시장 통계가 아니라 현재 역량을 기준으로 한 전략 평가다.

| 순위 | 제품 | 적합성 | 차별성 | 매출성 | 제작 난도 | 종합 |

| 1 | Safety Scenario Studio | 5 | 5 | 5 | 3 | 89/100 |

## 1. Safety Scenario Studio

### MVP 입력

- 작업종류
- 교육대상
- 장비·센서
- 현장환경
- 반드시 교육할 행동
- 금지 연출
- 평가 방식

### 출력

- 사고 전조
- 잘못된 행동 후보
- 시나리오 분기
- 센서·판정 조건
- 피드백 문구
- 난이도 변형
- 콘텐츠 제작 체크리스트

### 차별점

일반 LLM이 스토리만 생성하는 것과 달리, 체험 장치·센서·UI·판정·교육효과까지 하나의 제작 명세로 묶는다.

## 2. IP Harvest & Design-Around

### MVP

- 문제 브리프
- 기존 구조
- 필수 효과
- 회피해야 할 선행구조
- 활용 가능한 자산

### 출력

- 해결 공간 지도
- 발명 후보 10~20개
- 중복 클러스터
- 기술 구성·연결·작동·효과
- 검색 키워드
- 실험 증거 계획

### 판매 방식

- 발명 발굴 워크숍 + SaaS
- 기업 R&D팀 라이선스
- 특허사무소 파트너판

## 3. Game LiveOps Forge

### MVP

- 장르·핵심 루프
- 현재 콘텐츠
- 플레이어 피로 지점
- 경제·전투 제약
- 업데이트 목표

### 출력

- 시즌 테마
- 이벤트 루프
- 몬스터·보스·스킬
- 다회차 조건
- 운영 위험
- 플레이테스트 질문

## 4. 3D Concept Variation Lab

### MVP

- 사용 목적
- 엔진·플랫폼
- 폴리곤·재질·리깅 제약
- 제작기간
- 스타일·금지 요소

### 출력

- 실루엣 후보
- 구조·부품·재질
- 정면/측면/후면 요구
- LOD·텍스처·본 구조
- 이미지 생성 프롬프트
- 모델링 작업분해

## 5. AI Pet/NPC Behavior Studio

### MVP

- 성격 상태
- 기억 요약
- 현재 욕구
- 관계 단계
- 금지 행동
- 게임 상황

### 출력

- 반응 후보 분포
- 감정·행동·대사
- 기억 저장 여부
- 성장 신호
- 희귀 반응
- 안전·일관성 검증

## 권장 착수

첫 공개 데모는 범용으로 만들되, 첫 유료 파일럿은 **Safety Scenario Studio**로 진행한다. 이미 보유한 안전·VR·시뮬레이터 지식이 데이터·평가·고객 접근성에서 가장 큰 차별점이 된다.
