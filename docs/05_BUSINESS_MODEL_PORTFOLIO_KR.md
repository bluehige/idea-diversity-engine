# 05. 사업모델 포트폴리오

## 1. 사업화의 핵심 판단

VS 프롬프트 자체는 짧고 복제하기 쉽다. 따라서 방어력은 프롬프트 문구가 아니라 다음 자산에서 만들어야 한다.

- 도메인별 입력 스키마
- 의미 중복 제거 메모리
- 품질·위험 평가 루브릭
- 실제 사례와 평가 데이터셋
- 문서·툴·업무시스템 통합
- 인간 검수와 승인 워크플로
- 조직별 보안·감사·온프레미스

즉, 무료 공개 코어로 신뢰를 얻고, **도메인 워크플로와 평가·운영**을 유료화하는 오픈코어 전략이 적합하다.

## 2. 수익모델 후보

### 2.1 무료 오픈소스 코어

무료:

- 기본 프롬프트
- 3개 핵심 스킬
- JSON Schema
- CLI 검증기
- 샘플 브리프

목적:

- 검색 유입
- 신뢰 형성
- 사용자 피드백
- 통합 파트너 확보

### 2.2 개인용 SaaS

기능:

- 프로젝트 저장
- 후보 비교·핀·병합
- Direct/List/VS 비교
- 내보내기
- 모델 선택

가격 가설:

- Free: 월 제한 생성
- Creator: 월 12,000~29,000원
- Pro: 월 39,000~79,000원

이는 시장 검증 전 가설이며 모델 비용과 타깃에 따라 조정한다.

### 2.3 팀 워크스페이스

기능:

- 공유 프로젝트
- 과거 후보 의미 메모리
- 팀 평가·투표·승인
- 프롬프트·루브릭 버전관리
- 감사로그
- 역할 권한

과금 가설:

- 좌석 + 사용량
- 프로젝트 단위
- 부서 라이선스

### 2.4 수직 도메인 팩

별도 판매 가능한 팩:

- Safety Scenario Pack
- Patent Harvest Pack
- Game LiveOps Pack
- 3D Concept Pack
- Software Edge-Case Pack
- Research Hypothesis Pack
- Marketing Campaign Pack

각 팩은 프롬프트만이 아니라 `입력 폼 + 스키마 + 평가표 + 예제 + exporter`를 포함해야 한다.

### 2.5 API·MCP 사용량 과금

대상:

- 기존 사내 에이전트
- 콘텐츠 CMS
- 게임 운영툴
- 특허 관리 시스템
- 데이터 생성 파이프라인

과금 단위:

- 포트폴리오 생성 건수
- 후보 수
- 평가·임베딩 건수
- 저장 메모리 용량

### 2.6 온프레미스·화이트라벨

민감한 R&D/IP/산업 고객에게 제공한다.

- 설치비
- 연간 유지보수
- 사용자 수 또는 서버 수 라이선스
- 도메인 커스터마이징 비용

### 2.7 워크숍·컨설팅

초기 수익화에 가장 빠르다.

상품 예:

- 2~4시간 아이디어 다양성 워크숍
- 발명 발굴 스프린트
- 안전 콘텐츠 시나리오 발굴
- 게임 업데이트 콘텐츠 포트폴리오
- 사내 프롬프트·평가체계 구축

워크숍 결과를 툴에 축적하면 이후 SaaS의 도메인 데이터와 사례가 된다.

### 2.8 데이터셋·평가 서비스

- 중복률·커버리지 평가
- 모델별 Direct/List/VS 벤치마크
- 회사 내부 아이디어 동질화 진단
- 합성데이터 커버리지 보고서

이 서비스는 단순 생성보다 B2B 설명력이 높다.

## 4. 원가와 마진 설계

VS는 후보와 점수를 함께 생성하므로 단일 응답보다 토큰과 지연이 늘어난다. v4 논문은 특정 실험 설정에서 VS-Standard가 Direct 대비 비용 약 12%, 지연 약 23% 증가로 다양성 약 86% 증가했다고 보고한다. 실제 제품 원가는 모델·프롬프트·후보 길이마다 다시 측정해야 한다.

비용 절감 원칙:

- 1차 층화·정규화는 저가 모델
- 최종 후보·평가는 고성능 모델
- `k=5` 소규모 배치
- 목표 후보 수 도달 시 조기 종료
- 동일 브리프 캐시
- 중복 후보만 부분 재생성
- 임베딩은 로컬 또는 저가 모델
- 사용자에게 예상 비용 표시

## 5. 진입 전략

### 1단계 — 공개 신뢰

- GitHub 공개
- 논문 설명과 정확한 한계
- 비교 데모
- 실제 도메인 예제

### 2단계 — 전문성 증명

- 안전·게임·IP 사례 3개
- Direct 대비 중복 감소 데이터
- 사용자 선택 시간과 채택률

### 3단계 — 유료 검증

- 워크숍 3건
- 파일럿 기관 1~2곳
- 수직 팩 선판매

### 4단계 — 제품화

- 팀 워크스페이스
- API/MCP
- 기업 보안

## 6. 방어력

가장 강한 해자는 다음 순서다.

1. 도메인 사례·평가 데이터
2. 조직의 과거 아이디어 의미 메모리
3. 실제 업무 문서 exporter
4. 도메인 전문가 검수 네트워크
5. 배포·보안·권한 통합
6. 프롬프트 문구

프롬프트만 유료화하면 쉽게 복제된다. 결과를 업무에 연결하는 전체 시스템을 판매해야 한다.
