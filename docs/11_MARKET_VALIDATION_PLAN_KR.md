# 11. 시장 검증 계획

## 1. 검증할 핵심 가설

1. 사용자는 ‘더 많은 아이디어’보다 ‘의미적으로 다른 후보’를 원한다.
2. 전형성 표시와 탐색층이 후보 비교를 쉽게 만든다.
3. 수직 문서 exporter가 단순 챗봇보다 지불가치를 만든다.
4. 안전·IP·게임 중 안전 분야의 초기 전환이 가장 높다.
5. 공개 코어가 컨설팅·기업 파일럿으로 연결된다.

## 2. 4주 검증

### 1주차 — 공개

- GitHub 저장소
- 5분 설명 영상 또는 GIF
- Direct/List/VS 비교 예제 3개
- 관심 분야 설문

### 2주차 — 사용자 테스트

대상 10명:

- 안전 콘텐츠 3
- 게임·콘텐츠 3
- R&D·IP 2
- 일반 기획 2

측정:

- 유효 후보까지 시간
- 후보 중복 인식
- 선택 후보 수
- 수정량
- 다시 쓸 의향

### 3주차 — 수직 랜딩

Safety Scenario Studio 랜딩 페이지와 샘플 보고서를 공개한다.

CTA:

- 무료 브리프 진단
- 파일럿 신청
- 워크숍 문의

### 4주차 — 유료 신호

- 소액 유료 워크숍 또는 문서 제작
- 실제 브리프 3건 수행
- 결과 채택·수정·납기 측정

## 3. A/B 평가

동일 브리프로 비교:

- Direct: 한 번에 하나
- List: 5개 목록
- VS: 후보+전형성
- Stratified VS: 층화+VS

지표:

- semantic diversity
- duplicate rate
- constraint pass rate
- 인간 품질 점수
- 최종 채택률
- 작업시간
- 토큰비용

## 4. 중단 기준

다음이면 범용 SaaS 개발을 늦춘다.

- 사용자가 후보 차이를 체감하지 못함
- 문서 exporter 없이도 일반 챗봇으로 충분하다고 평가
- 수직 분야에서 반복 사용이 없음
- 모델 비용이 지불의사 대비 과다

이 경우 오픈소스+컨설팅 또는 특정 도메인 내부 도구로 범위를 축소한다.

## 5. 성공 기준

초기 30일 제안 기준:

- 외부 사용자 30명
- 실제 프로젝트 10개
- 완료 내보내기 20건
- 유료 또는 파일럿 의향 3건
- 수직 분야 재사용 2회 이상 고객 2곳
- Direct 대비 중복률 30% 이상 감소
