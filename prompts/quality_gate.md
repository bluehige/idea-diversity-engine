# Diversity and Quality Gate

Evaluate the supplied portfolio without using low typicality as evidence of quality.

Return for every candidate:

- hard-constraint verdict
- semantic duplicate cluster
- relevance
- clarity
- feasibility
- expected effect
- factual support requirements
- safety and legal risks
- accept / repair / merge / reject

Also return portfolio-level:

- semantic diversity
- duplicate rate
- stratum coverage
- typicality-band coverage
- average quality
- cost and latency metadata when available
