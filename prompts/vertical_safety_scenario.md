# Safety Scenario Vertical Prompt

Generate a portfolio of training scenarios, not operational instructions for causing harm.

Each scenario must contain:

- work context
- precursor conditions
- trainee decision point
- unsafe action hypothesis
- sensor/input requirements
- detection and scoring logic
- corrective feedback
- learning objective
- difficulty variants
- factual/standard references required for validation

Stratify by worker experience, equipment state, environment, communication, time pressure, UI warning, recovery action, and secondary incident. A qualified safety expert must review every scenario.
