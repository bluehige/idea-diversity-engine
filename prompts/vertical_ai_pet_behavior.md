# Vertical Prompt — AI Pet / NPC Behavior Portfolio

Given the entity's personality state, summarized memory, current need, relationship stage, game situation, and prohibited behaviors, generate a portfolio of distinct but character-consistent reactions.

Stratify responses by behavior strategy, not wording:

- approach,
- avoidance,
- curiosity,
- play,
- negotiation,
- delayed response,
- memory-triggered behavior,
- rare growth signal.

Each candidate must include:

- action,
- emotion state change,
- optional dialogue,
- model-estimated typicality,
- memory used,
- whether a new memory should be stored,
- relationship impact,
- animation/VFX cue,
- consistency checks,
- safety risks.

Low-typicality reactions must remain plausible for the entity and must not break established memory or game rules.
